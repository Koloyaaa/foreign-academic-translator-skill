## 强制 Skill 使用声明

- 在本 Skill 开始实质工作前，先向用户单独输出一行：`当前使用 Skill：foreign-academic-html-publisher`。如果编排器已在进入本阶段前输出了这一行，不重复。
- 硬性阶段门禁：编排器必须在调用目标 Skill 前，先单独向用户输出 `当前使用 Skill：<skill-name>`；没有编排器时，由目标 Skill 自行先输出。未出现目标 Skill 的声明行，不得启动该阶段。
- 只声明本轮真正执行的 Skill，不声明仅被列为候选或因缓存命中而跳过的 Skill。这是对话进度提示，不得写入讲义、译稿、测验或其他产物。

# HTML 发布 Skill

读取 .translation-task-pro.json 和 translated_markdown。只负责 HTML 构建和成品检查；不得重新翻译、删减、重排或改写正文，也不读取或保存偏好。共享脚本、CSS、词库和图片资源位于清单的 shared_runtime。

## 构建

只有编排器确认 HTML 阶段签名和产物哈希均命中时，才可直接检查已有文件。缓存未命中时，从 shared_runtime/scripts/builder.py 的绝对路径单独构建 HTML，每次只传 `--formats html`，并传入 show_concept_table 与 layout；interactive-quiz-required 只有在 quiz_levels 含具体难度时为 true。必须确认本次构建退出码为 0、返回的路径正是 `output_dir/translated_doc.html` 且文件非空，才进入成品检查。同名旧文件即使存在，也不能证明本次构建成功；不得绕过错误或手动删改源内容来伪造通过。

## 检查

确认文件存在且非空，构建器门禁通过。正文可见文本必须通过乱码门禁：不得出现 Unicode 替换字符、常见 UTF-8 错误解码序列、可见的 HTML 标签/实体源码或异常控制字符。代码块中的标签示例可保留；正文中出现截图所示 `</span>` 一类源码片段时必须判失败，报告片段和附近位置，退回修复统一 Markdown/编码并重建，不能删掉异常字符后直接放行。核对双侧导航、知识大纲、滚动高亮、阅读进度、主题和明暗控件、术语概念表、图片引用与正式名称页脚；来源页码须居中显示为浅色细线夹注，不得破坏原页码文字。测验被选中时核对交互卡片数与题数一致，每题有 A-D、唯一有效答案、非空解析和独立提交按钮。能实际打开页面时检查交互；只能静态检查时说明这一点。

检查数学公式时，确认生成 HTML 的 MathJax 配置在 JavaScript 字符串中保留了“反斜杠+圆括号”行内定界符和“反斜杠+方括号”行间定界符。实际预览不得把公式定界符或 TeX 命令显示为正文。能打开页面时确认公式已经排版；若公式仍以 TeX 源码显示，视为 HTML 格式缺陷并退回修复。MathJax CDN 无法加载时明确标注公式渲染未验证，不能报告公式检查通过。

遇到语义、漏译或原文结构问题时，把定位信息退回编排 Skill，由翻译或审计流程修正共同 Markdown；共享译稿改变后重新构建全部所选格式。只在 HTML 局部渲染失败时重建 HTML。不得为通过 HTML 门禁擅自改变源文内容。

## 阅读器功能基线

- 桌面布局为贴住左右窗口边缘、占满可视高度的双侧导航；窄屏时导航移到正文上方。左侧是可折叠的 output 文件树，根目录和子目录均可折叠，文件、文件夹和箭头使用 Font Awesome 图标，并链接其他 HTML 学案。
- 右侧知识大纲静态写入页面、始终展开，不提供折叠按钮；标题滚动高亮并自动滚到可见位置。目录标题覆盖正文 H1 至 H4，数量一致。
- 正文桌面上外边距为 16px、上内边距为 24px。课程信息位于紧凑页眉而非大纲标题；concept_highlight 的 H1 为中文主题，原文主题在下一行居中小字显示。
- 右上角配色与明暗是两个独立控件，分别支持蓝、青绿、紫、琥珀，以及浅色、深色、跟随系统；默认蓝色浅色。个人设置保存在浏览器本地。
- 用户可选中文本并创建高亮或注释，标记可查看、编辑和删除；新标记不得与已有高亮重叠。阅读栏支持鼠标拖动及键盘方向键调整宽度，阅读宽度和标记保存在浏览器本地。
- 阅读进度按正文滚动范围计算；启用概念表时将概念表纳入范围。交互测验每题独立提交，提交后才显示该题答案和解析。
- 公式和 Font Awesome 图标通过 CDN 加载；离线时需报告公式可能显示为 LaTeX 源码、图标可能缺失。若无法实际打开并操作页面，只能报告静态检查结果。
