# Prompt 库

这些提示词用来一次说明讲义翻译需求。先按[项目安装说明](../README.md)选择并安装一个档位，再选一份模板，复制后填好方括号里的档位、入口名称和其他信息，最后附上讲义。格式、布局、注释、术语、配图和测验选项都可以按需修改。

## 档位与入口

| 档位 | 模板中的入口 Skill 名称 | 工作方式 |
| --- | --- | --- |
| Lite | `foreign-academic-translator-lite` | 旧版翻译流程，交付前做文件可读性检查 |
| Plus | `foreign-academic-translator-plus` | 旧版翻译流程，加独立质量审计 |
| Pro | `translation-orchestrator` | 新版技能组，每个 Skill 完成后决定下一步 |
| Max | `translation-orchestrator` | 新版技能组，按现有完整工作流处理适用阶段 |

例如，使用 Lite 时，把模板首句中的 `[档位]` 填为 `Lite`、`[入口 Skill 名称]` 填为 `foreign-academic-translator-lite`。Pro 和 Max 的入口同名，但各自使用所安装档位的独立技能组；切换档位时请按安装说明更换完整套件。

Lite、Plus 适合旧版可处理的 PDF、DOCX、TXT 或纯文本；旧版配图提取仅支持 PDF。PPTX、扫描件和结构复杂的材料建议选 Pro 或 Max。Plus 需要在独立审阅上下文中运行质量审计 Skill；如果宿主无法提供该能力，会报告阻塞，不能声称审计通过。

## 提示词模板

| 提示词 | 适合的情况 |
| --- | --- |
| [自定义模板](custom.md) | 自己选择各项输出设置 |
| [日常预习](preview.md) | 想先用中文读懂讲义，保留常用术语 |
| [双语对照](bilingual.md) | 希望逐段对照原文与译文 |
| [考前复习](exam-review.md) | 希望获得解释、概念表和章末测验 |
| [简洁译文](concise.md) | 只需要便于阅读和保存的中文译稿 |

入口会按所选档位处理读取、翻译和发布；Plus、Pro、Max 还要求独立质量审计。Pro 和 Max 使用新版读取与视觉核对流程。各模板是使用示例，不是额外的 Skill。实际执行的 Skill 会按套件要求在对话中报出名称。

Pro 和 Max 处理 PDF/PPTX 时，配图只有在开启配图且图片经过视觉核对并被选中时才会插入。当前宿主和模型能够接收页面图像时，流程必须逐页核对；确实无法传递图像时会说明未审核页及处理限制。选择“不插入配图”不会关闭视觉核对。Lite 和 Plus 的旧版处理能力以对应档位说明为准。

提示词的表达参考 `humanizer-zh`：用自然、具体的语言交代需求，保留必要信息，不靠冗长的角色设定或空泛的修饰语。
