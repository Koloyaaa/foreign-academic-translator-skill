# 自定义模板

先按[档位与入口对照表](README.md#档位与入口)填写首句，再把其他方括号换成你的选择；不确定的内容可以删掉，让所选档位按材料和已有偏好处理。

```text
请使用 [档位] 档的 `[入口 Skill 名称]` Skill，将附件中的外文讲义翻译成准确、易读的中文学案。我的具体要求如下：

附件是《[文件名]》，供[课程、读者或用途]使用。请输出为[HTML / DOCX / Markdown，可多选]。正文采用[仅译文 / 每段译文在前、原文在后 / 每段原文在前、译文在后 / 仅译文并在术语首次出现时标注原文]的布局。[需要 / 不需要]文末概念表，注释选择[无注释 / 轻度注释 / 高中生视角 / 重度注释]；配图[需要 / 不需要]插入，请按所选档位支持的范围处理。术语请[使用随包词库 / 根据上下文识别]。

章末测验选择[无测验 / 基础 / 中档 / 高难，可多选]；如果需要测验，题目和解析使用[中文 / 学案所属语言 / 双语]。其他具体要求：[填写或删除]。
```

选择“无测验”时删掉测验语言；选择其他难度时保留语言。学科和源语言通常可以由所选入口根据讲义判断。
